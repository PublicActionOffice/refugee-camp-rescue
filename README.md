# 難民キャンプを救え!

[ブラウザーでゲームを遊ぶ](https://publicactionoffice.github.io/refugee-camp-rescue/)

予算100万円で、架空の難民キャンプに到着した100人への初日の支援を考える日本語の意思決定ゲームです。

## 遊び方

`index.html` をブラウザーで開くだけで動きます。インストールや外部サービスへの接続は不要です。08:00から21:00まで6つの場面で1つずつ行動を選び、支援の結果を確認してください。予算を超える選択はできません。最後に医療・水・住居・食事・衛生・住民参加を振り返ります。リロードすると最初に戻ります。

- 子ども35人、高齢者15人、その他の成人50人（このうち負傷者5人）
- 初期物資：テント10張り（ゲームでは1張り5人）、水50人分
- 水と食事の人数は初日の配布量、テントは確保数です。
- 同じ支援を繰り返すと予算は消費します。治療済みの負傷者は重複して数えません。
- 費用・効果・状況は学習用の仮定です。実際の緊急支援の手順や費用の目安ではありません。

## 検証

Node.jsがある環境で `node test.cjs` を実行。予算内の全選択経路を列挙し、完走可能性、予算の非負、重複選択の防止、支援目標を満たす経路の存在を確認します。

## GitHub Pagesで公開

1. 公開リポジトリを作成します。
2. このフォルダーのファイルをリポジトリのルートにアップロードします。
3. Settings → Pages → Build and deploymentで「Deploy from a branch」を選びます。
4. Branchで `main` と `/(root)` を選び、Saveします。
5. 表示される公開URLを開きます。

静的HTML/CSS/JavaScriptのみで動作します。外部フォント、解析ツール、利用者情報の送信はありません。


## 場面から学ぶ

6場面それぞれに写実的なAI生成イラスト、短い解説、2択の確認問題を追加しています。確認問題を解かずに次へ進むこともできます。終了後は選んだ行動と学びを読み返し、次に変えたい判断をメモできます。メモは画面上だけで保持され、送信・保存されません。

参考資料は [Sphere Handbook](https://spherestandards.org/handbook/) と [CHS 2024](https://www.corehumanitarianstandard.org/the-standard) です。公式教材ではなく、解説・問いは本ゲーム独自のものです。

画像は `assets/` 内の6枚です。内蔵ImageGenで作成したプロンプトは [assets/PROMPTS.md](assets/PROMPTS.md) に記録しています。画像中の人数・物資はシミュレーションの状態や選択結果を表しません。
